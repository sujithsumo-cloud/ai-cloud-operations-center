
# AI Cloud Operations Center

## Project Overview

The AI Cloud Operations Center (AI COC) is a cloud operations
project designed to monitor an AWS-hosted web server, detect
service failures, and automate recovery.

The project will be implemented incrementally using Infrastructure
as Code and AWS-native monitoring and remediation services.

## Objectives

- Provision AWS infrastructure using Terraform.
- Monitor web server health and system metrics.
- Detect service failures using Amazon CloudWatch.
- Automate recovery using AWS Lambda and AWS Systems Manager.
- Send incident notifications using Amazon SNS.
- Maintain project history and collaboration through Git and GitHub.

## Technology Stack

- AWS EC2
- Amazon VPC
- AWS IAM
- Amazon CloudWatch
- AWS Lambda
- AWS Systems Manager
- Amazon SNS
- Terraform
- Python
- Git and GitHub

## Project Principles

- Infrastructure as Code.
- Least-privilege IAM permissions.
- Incremental implementation and testing.
- No EventBridge dependency.
- No AWS resources created without reviewing the Terraform plan.
